# Bookmarklets

Small browser bookmarklets for SEO and web workflows.

## Google Search Console — Current page

Opens the current URL you're viewing in the Google Search Console Performance report for the current domain.

### Install

1. Create a new bookmark in your browser.
2. Give it a name such as `GSC Current Page`.
3. Paste the code from [`gsc-current-page.js`](./gsc-current-page.js) into the bookmark URL field, then save the bookmark.
4. Open a page from a domain you have access to in GSC, then click the saved bookmarklet. It will open that URL in GSC for you to analyze.
